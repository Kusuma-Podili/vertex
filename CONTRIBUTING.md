# Contributing Guidelines

Thank you for contributing to the Enterprise E-Commerce Platform!

## Code Quality Standards
- All code must be strictly typed TypeScript.
- Follow ESLint and Prettier formatting guidelines (`npm run lint`, `npm run format`).
- Write unit or integration tests for every new business feature.
- Ensure all test suites pass (`npm test` or `python run_tests.py`).

## Commit Convention
We follow the Conventional Commits specification:
- `feat(module)`: A new feature
- `fix(module)`: A bug fix
- `docs(scope)`: Documentation only changes
- `test(scope)`: Adding or correcting tests
- `refactor(module)`: Code change that neither fixes a bug nor adds a feature
- `chore(scope)`: Build process, dependencies or tooling changes

# Changelog

All notable changes to this project will be documented in this file.

## [1.0.0] - 2026-08-27
### Added
- Monorepo structure with Turborepo orchestration.
- Comprehensive Prisma ORM schema with 35+ domain models.
- Shared TypeScript types, DTO validation schemas, and mathematical utility packages.
- NestJS Modular Backend with 14 enterprise services.
- Next.js 14 Customer Storefront with full checkout flow.
- React Admin & Merchant backoffice dashboard with live metrics.
- BullMQ asynchronous worker pipeline.
- Over 50+ unit, integration, and E2E automated test cases.
- Multi-container Docker Compose and CI/CD pipelines.
